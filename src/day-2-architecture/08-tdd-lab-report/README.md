# Dzień 2, Moduł 8: TDD — generator opisów badań

**Test-Driven Development** to praca w krótkim cyklu: najpierw test, który nie przechodzi (**Red**), potem najprostszy kod, który go spełnia (**Green**), a na końcu porządki bez zmiany zachowania (**Refactor**). Testy prowadzą projekt, a refaktoryzacja jest bezpieczna, bo każdy krok jest sprawdzony.

Moduł zamyka dzień 2: zamiast refaktoryzować gotowy kod, budujemy mały komponent od zera i obserwujemy, w którym momencie testy same zaczynają domagać się lepszej struktury.
